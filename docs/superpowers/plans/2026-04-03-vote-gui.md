# Vote GUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "Current Motion" tab and voting interface to the Internationale Congress GUI window.

**Architecture:** Extends `internationale_gui.gui`. Uses `GetVariableSystem` for UI tab state (existing pattern). Reads global variables for vote state. A new "Current Motion" tab clears all faction tabs — when no faction tab is set the motion screen is shown. The voting interface uses a three-column hbox: current law | status/prestige bar | proposed law.

**Tech Stack:** Victoria 3 GUI scripting. Read `gui/internationale_gui.gui` before starting — understand the existing tab pattern and vbox structure.

**Read first:** `docs/superpowers/specs/2026-04-03-vote-gui-design.md` and `docs/superpowers/specs/2026-04-03-vote-lifecycle-design.md`

**Prerequisite:** Vote lifecycle plan must be implemented first (global variables must exist).

## Task 1: Add "Current Motion" Tab Button

**Files:**
- Modify: `gui/internationale_gui.gui`

The faction tab buttons are in an `hbox` around line 161. Add a sixth tab button as the first entry, styled distinctly (neutral grey/gold).

- [ ] **Step 1: Find the faction tab hbox**

Read `gui/internationale_gui.gui` lines 160–300 to locate the `### FACTION TAB BUTTONS` hbox.

- [ ] **Step 2: Add "Current Motion" tab as first button in the hbox**

Insert before the first `intl_tab_button` block:

```pdx
# Current Motion tab — shows neutral/vote screen when active (no faction tab set)
intl_tab_button = {
	blockoverride "tab_color" {
		color = { 0.7 0.65 0.4 1 }
	}
	blockoverride "tab_text" {
		text = "intl_tab_current_motion"
	}
	blockoverride "tab_active_visible" {
		visible = "[And(Not(GetVariableSystem.Exists('intl_tab_anarchist')), And(Not(GetVariableSystem.Exists('intl_tab_mutualist')), And(Not(GetVariableSystem.Exists('intl_tab_syndicalist')), And(Not(GetVariableSystem.Exists('intl_tab_blanquist')), Not(GetVariableSystem.Exists('intl_tab_marxist'))))))]"
	}
	blockoverride "tab_inactive_visible" {
		visible = "[Or(GetVariableSystem.Exists('intl_tab_anarchist'), Or(GetVariableSystem.Exists('intl_tab_mutualist'), Or(GetVariableSystem.Exists('intl_tab_syndicalist'), Or(GetVariableSystem.Exists('intl_tab_blanquist'), GetVariableSystem.Exists('intl_tab_marxist')))))]"
	}
	blockoverride "tab_onclick_set" {
		onclick = "[GetVariableSystem.Clear('intl_tab_anarchist')]"
		onclick = "[GetVariableSystem.Clear('intl_tab_mutualist')]"
		onclick = "[GetVariableSystem.Clear('intl_tab_syndicalist')]"
		onclick = "[GetVariableSystem.Clear('intl_tab_blanquist')]"
		onclick = "[GetVariableSystem.Clear('intl_tab_marxist')]"
	}
	blockoverride "tab_onclick_clear" {
		# No-op: clicking again does nothing (already neutral)
	}
}
```

- [ ] **Step 3: Add loc key**

In `localization/english/intl_vote_l_english.yml`:
```yaml

```

- [ ] **Step 4: Verify**

Load game, open the Congress window. New tab "Current Motion" should appear. Clicking it should deselect all faction tabs.

- [ ] **Step 5: Commit**


## Task 4: Scripted Widgets — Law Panel and Center Status

**Files:**
- Create: `gui/scripted_widgets/intl_vote_widgets.txt`

- [ ] **Step 1: Create the widgets file**

```pdx
# Internationale Vote — Scripted Widgets

# Law panel used for both current and proposed sides
# Blocks: vote_side_label, vote_side_var
types intl_vote_types {

	type intl_vote_law_panel : widget {
		size = { 100% 100% }

		vbox = {
			layoutpolicy_horizontal = expanding
			spacing = 6
			margin = { 8 8 }

			# Side label (Current Law / Proposed Law)
			textbox = {
				size = { 100% 30 }
				block "vote_side_label" { text = "" }
				using = fontsize_medium
				align = hcenter|nobaseline
				alpha = 0.7
			}

			# Law name — displayed from global variable ideology index
			# Note: law display name requires custom loc; use ideology name as fallback
			textbox = {
				size = { 100% 36 }
				text = "intl_vote_law_name_placeholder"
				using = fontsize_large
				align = hcenter|nobaseline
			}

			# Supporter count
			hbox = {
				spacing = 4
				parentanchor = hcenter
				textbox = {
					text = "intl_vote_supporters_label"
					using = fontsize_small
					alpha = 0.6
				}
				block "vote_side_var" {}
			}

			# Vote button — only visible if player hasn't voted
			button_standard = {
				size = { 200 36 }
				parentanchor = hcenter
				visible = "[Not(GetPlayer.MakeScope.Trigger('intl_country_has_voted'))]"
				blockoverride "button_text" {
					text = "intl_vote_cast_button"
				}
				# onclick defined per side in the parent widget (to pass SIDE parameter)
				# See Task 5 for onclick wiring
			}

			# Already voted label
			textbox = {
				size = { 100% 30 }
				text = "intl_vote_already_voted"
				using = fontsize_small
				align = hcenter|nobaseline
				alpha = 0.5
				visible = "[GetPlayer.MakeScope.Trigger('intl_country_has_voted')]"
			}
		}
	}

	# Center status panel
	type intl_vote_center_status : widget {
		size = { 100% 100% }

		vbox = {
			parentanchor = center
			spacing = 10
			margin = { 4 8 }

			# VS separator
			textbox = {
				size = { 100% 40 }
				text = "VS"
				using = fontsize_xxl
				align = hcenter|nobaseline
				alpha = 0.5
			}

			# Months remaining
			textbox = {
				size = { 100% 30 }
				text = "intl_vote_months_left_label"
				using = fontsize_medium
				align = hcenter|nobaseline
			}

			# Prestige bar container
			widget = {
				size = { 180 24 }
				parentanchor = hcenter

				# Background (proposed side — full width)
				widget = {
					size = { 100% 100% }
					background = {
						color = { 0.6 0.2 0.2 1 }
					}
				}

				# Foreground (current side — proportional width)
				# Width = intl_vote_prestige_current / (current + proposed) * 180
				# Approximated via progressbar
				progressbar = {
					size = { 100% 100% }
					value = "[GetGlobalVariable('intl_vote_prestige_current').GetValue(int32)]"
					max = "[Add(GetGlobalVariable('intl_vote_prestige_current').GetValue(int32), GetGlobalVariable('intl_vote_prestige_proposed').GetValue(int32))]"
					color = { 0.2 0.4 0.7 1 }
				}
			}

			# Prestige numbers
			hbox = {
				spacing = 8
				parentanchor = hcenter
				textbox = {
					size = { 80 24 }
					text = "[GetGlobalVariable('intl_vote_prestige_current').GetValue(int32).ToString]"
					using = fontsize_small
					align = right|nobaseline
					alpha = 0.8
				}
				textbox = {
					size = { 20 24 }
					text = "/"
					using = fontsize_small
					align = hcenter|nobaseline
					alpha = 0.4
				}
				textbox = {
					size = { 80 24 }
					text = "[GetGlobalVariable('intl_vote_prestige_proposed').GetValue(int32).ToString]"
					using = fontsize_small
					align = left|nobaseline
					alpha = 0.8
				}
			}
		}
	}
}
```

## Task 5: Wire Vote Buttons

**Files:**
- Modify: `gui/internationale_gui.gui`

The vote buttons need `onclick` handlers. The current law panel votes SIDE = 1, proposed votes SIDE = 2.

- [ ] **Step 1: Add onclick to current law panel in the vote interface widget**

In the `intl_vote_current_panel` widget, add an `onclick` override. Since scripted widgets can't easily pass parameters via onclick, the simplest approach is to add two separate named button widgets directly in the GUI (not via the shared widget type):

Replace the `intl_vote_current_panel` widget content:

```pdx
### LEFT — CURRENT LAW (with vote button hardcoded for SIDE=1)
widget = {
	size = { 360 300 }
	name = "intl_vote_current_panel"
	# ... law panel content inline, ending with:
	button_standard = {
		size = { 200 36 }
		parentanchor = hcenter
		visible = "[Not(GetPlayer.MakeScope.Trigger('intl_country_has_voted'))]"
		text = "intl_vote_keep_button"
		onclick = "[GetPlayer.MakeScope.Effect('intl_cast_vote', 'SIDE', '1')]"
	}
}
```

Do the same for the right panel with `SIDE = 2` and text `intl_vote_support_button`.

> **Note:** Vic3 GUI `onclick` effect syntax is `"[Scope.Effect('effect_name', 'PARAM', 'value')]"`. Verify this is supported for country-scoped effects on `GetPlayer`. If not, use a button that triggers a country event with option effects instead.

- [ ] **Step 2: Add loc keys**

```yaml
  intl_vote_keep_button: "Keep Current Law"
  intl_vote_support_button: "Support Proposal"
```

Load game, start a vote via console, open Congress window, click a vote button. Check `intl_vote_stance` is set on player country.
